## Quality Scoring (0-100)

**Base Score**: 50 points

### Add Points For

| Criterion | Points | Description |
|-----------|--------|-------------|
| 40+ words | +10 | 2+ second dwell time |
| Discussion starter | +10 | Question or open prompt (triggers 13.5-27x reply boost) |
| Practical/actionable | +10 | Specific tips or insights |
| Personal experience | +10 | Real anecdotes included |
| Natural voice | +10 | Human patterns, no AI tells |
| Media included | +10 | Images/video = 2-3x engagement boost |
| White space | +5 | Good formatting |
| Platform-native | +5 | X-specific language |
| Shows emotion | +5 | Genuine reactions |

### Deduct Points For

| Criterion | Points | Description |
|-----------|--------|-------------|
| Thread format | -50 | AUTOMATIC REJECTION |
| Offensive content | -50 | Zero tolerance (report = -369x) |
| ALL CAPS | -30 | Seen as shouting |
| Link in post | -25 | Severe penalty (put in reply instead) |
| AI phrases | -20 | "Let's dive in", etc. |
| Under 40 words | -15 | AUTO FLAG |
| Corporate structure | -15 | Too polished |
| No media | -10 | Missing 2-3x boost opportunity |
| Generic content | -10 | Obvious/boring |

**Minimum to Post**: 70/100

- [ ] Starts mid-thought or mid-conversation

- [ ] Natural contractions
- [ ] Emotional reaction

- [ ] Ends with question
- [ ] Personal pronoun start
- [ ] Admits confusion
- [ ] Informal capitalization

## AI Phrases to NEVER Use

These instantly flag content as AI-generated:

- "Let's dive into..." / "Let's explore..."
- "In today's digital landscape..."
- "It's worth noting that..."
- "Interestingly..." / "Notably..."
- "Here's what I learned:"
- "Unpopular opinion but..."
- "Thread 🧵" format
- Numbered lists in every post
- Perfect conclusions every time
- "In conclusion..." / "To summarize..."
- "At the end of the day..."
- "It goes without saying..."
- "Hot take:" / "The secret nobody talks about:"
- Forced contrarian positions
- Perfect 5-point frameworks

---

## Human Patterns to USE

### Natural Starting Patterns
- "spent 2 hours debugging..."
- "been using X for Y months..."
- "just switched from X to Y..."
- "3 attempts with [tool], no luck..."
- "gotta stay nimble with..."
- "honestly..." / "actually..." / "okay so..."

### Uncertainty Markers
- "still figuring this out..."
- "not sure if..."
- "might be wrong but..."
- "could be..." / "probably..."

### Discussion Starters (End Posts With)
- Open questions
- Incomplete thoughts
- "what do you think?" / "anyone else?" / "agree?"

## Content Structure Formula

```
[Hook: Specific experience - 15-25 words]

[Context: What happened - 20-30 words]

[Discussion prompt: Open question - 10-20 words]
```

**Total: 45-75 words ideal**

## Natural Language Checklist

- [ ] Sounds like something you'd actually say
- [ ] Would you text this to a developer friend?
- [ ] Starts naturally, not forced hook
- [ ] Real details (times, tools, costs)
- [ ] Okay to have incomplete thoughts
- [ ] Avoids AI influencer buzzwords
- [ ] Based on actual experience
- [ ] Shows honest uncertainty or failure

## Scoring Gate Protocol

**Auto-flag for drafts/ if:**
- Quality Score <70/100
- Engagement Average <3.0/5.0
- Word count <40
- Human Authenticity <3 elements
- Thread format detected

**Every flagged post gets actionable feedback. No rejections, only improvements.**
