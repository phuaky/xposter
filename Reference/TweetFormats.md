# Tweet Format Templates

**CRITICAL: Single Medium-Form Posts Only — NO THREADS**

---

## Template 1: Natural Experience

```
[What actually happened - specific situation]

[Your response or observation]

[Simple takeaway if there is one]
```

**Example:**
```
spent an hour with OPUS 4.1 trying to fix an auth bug. 3 attempts, no luck.

switched to GPT-5 on Codex ($20/month) - fixed it immediately.

gotta stay nimble with models. sometimes the expensive one isn't the better one.
```

**Range:** 200-280 characters

---

## Template 2: Simple Observation

```
[Time reference] [what you tried/used]

[What happened / result]

[Optional simple reflection]
```

**Example:**
```
been all-in on Claude Code for 2 months. yesterday added Codex to split terminal.

hearing good things about it. hoping to downgrade my Claude tier soon.

the 2-attempt rule keeps me from getting tunnel vision with any single model.
```

**Range:** 180-280 characters

---

## Template 3: Tool Switch

```
[Previous workflow/tool]

[New approach/tool]

[Simple comparison or reflection]
```

**Example:**
```
3 months ago with Cursor: switch between Claude, Gemini & GPT agents seamlessly

now: open separate CLI terminals for different models

not hard when you have subscriptions - just gotta be nimble
```

**Minimum:** 150 characters (~40 words)

---

## Template 4: Tool Comparison

```
[Tool A] vs [Tool B] for [use case]:

[Tool A]: [pros/cons]
[Tool B]: [pros/cons]

Winner: [choice with reasoning]
```

**Example:**
```
GitHub Copilot vs ChatGPT for debugging:

Copilot: Great for syntax, integrated workflow
ChatGPT: Better for complex logic, explanation

Winner: Use both. Copilot for speed, ChatGPT for understanding.
```

**Range:** 200-280 characters

---

## Content Structure Formula

```
[Hook: Specific experience - 15-25 words]

[Context: What happened - 20-30 words]

[Discussion prompt: Open question - 10-20 words]
```

**Total:** 45-75 words ideal

---

## Evidence Patterns

- Specific time savings: "2 hours → 2 minutes"
- Tool comparisons: "X vs Y for Z"
- Personal anecdotes: "Last week I..."
- Concrete examples: "Instead of writing 200 lines..."
- Statistics: "82% of developers now..."

---

## Value Propositions

- Time savings: "Save X hours per week"
- Skill development: "The skill that will matter most"
- Problem solving: "Finally solve the X problem"
- Future preparation: "Get ahead of the curve"

---

## Formatting Best Practices

- Use line breaks for readability
- Max 2-3 sentences per paragraph
- Emojis sparingly (optional)
- Aim for 200-270 characters (leave room for quotes)
- Use contractions to save space

---

## Quality Checklist

### Algorithm Compliance
- [ ] ≥40 words minimum
- [ ] Single post only (NO threads)
- [ ] 2+ second read time
- [ ] Ends with discussion starter
- [ ] No links, no ALL CAPS

### Natural Language
- [ ] Sounds like something you'd say
- [ ] Real details (times, tools, costs)
- [ ] Okay to be incomplete
- [ ] Avoids AI buzzwords

### Format
- [ ] Under 280 characters
- [ ] Under 5 sentences
- [ ] Proper line breaks
- [ ] No typos
