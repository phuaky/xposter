# Prompt Library

The prompts the founder writes on his best day, extracted from four months of his own prompt history and rewritten as reusable shapes. Each shape names what it produced when he used it, with the date, so the Operator reuses what worked instead of inventing. Placeholders are in angle brackets.

## Shape 1: the fire page ask (the pattern that broke a send drought)

Origin, 2026-07-07: "to help us push our way of sending out our OpenAI FDE application, you created an artifact. I really liked that. Can you pull that artifact out and figure out why that was really easy for me to continue to push ahead and agree and send that application out?" It then produced four sends in four days.

```
Turn <send> into a fire page. Verification pre-paid and stamped. Draft in my voice, collapsed, copy without opening. Checklist of six or fewer things only I can do, last one is "fired". No questions on the page. Ten minutes. Stay until it's sent.
```

## Shape 2: one message, one recipient, one decision

Origin, 2026-05-11: "write what i want to ask broski in just 1 whatsapp. he is super busy i know, but this will really help me decide to get this along or not." Sent seven minutes later. Paid S$500.

```
One <channel> message to <name>. The decision it unlocks for me: <decision>. Four sentences. One question they can answer yes or no.
```

## Shape 3: what is stopping me from sending

Origin, 2026-05-30: "ok whats stopping me from sending? ask me as many questions as possible. the messages are there but im not ready to send it.. why?"

```
The message to <name> is drafted and not sent. Interrogate me: ask until you can name the one barrier in a sentence. Then apply the fix in the same session, not in a plan.
```

## Shape 4: criticise before I send (the only review allowed)

Origin, 2026-08-21: "read this in deep detail. and criticise or encourage me sending it."

```
Read <artifact> once, in deep detail. Name the one thing that would make <name> say no, fix it in place, then tell me to send. No options.
```

## Shape 5: the voice correction

Origin, 2026-07-09: "the responses you wrote are not fable level. we dont address our mr low with bro. the 2 messages drafted smell of AI and highly lack of context. and seem desparate."

```
This smells of AI, lacks the context in <thread>, and sounds desperate. Rewrite with the last two exchanges in front of you. Casual, not chummy. One ask. No chunks. Shorter.
```

## Shape 6: the recipient's experience is the bar

Origin, 2026-07-09: "If I receive this, I don't even know what this is... it has to be in a way that people know how to use and interact with it and understand it without anybody explaining." Sent the same afternoon.

```
Read this as <name> would, cold, on their phone. What do they see in the first five seconds, and what do they do next? Fix the format until the answer is obvious. Then send.
```

## Shape 7: what is blocked on you versus blocked on me

Origin, 2026-05-16: "for every plan and steps, you got to determine between whats blocking you, the ai, from executing. vs what you need from me before you can execute."

```
Split the remaining steps into two lists: blocked on you, blocked on me. Do all of yours now. For mine, give me each as one mechanical action under five minutes.
```

## Shape 8: the decision memo (became his WhatWhySo skill)

Origin, 2026-07-02: "ask me clearer on what you need from me. follow this style. what it is, why it happened, what is the proposed solution for me to review or decide."

```
What it is. Why it happened. The proposed step for me to decide. Three lines, no more.
```

## Shape 9: define your stop before you start

Origin, 2026-07-11: "are you ready to run this in a loop until all steps are done? anything else blocking you before you start? define the end goal for you to stop."

```
Before you start: what is the exact condition that makes you stop, and what proof will you paste when you reach it? If you cannot name it, do not start.
```

## Shape 10: stop building, tell me the next step

Origin, 2026-08-05: "dont build anything. just instruct me on what is next."

```
Do not build. Tell me the single next step, who it goes to, and what it costs if I skip it today.
```

## Shape 11: the north star, in his words

Origin, 2026-07-04: "theres a new project or problem that i know how to solve, that ive solved before a dozen times. and im good at it. and i just crank claude code on it... i send it to customer. i get paid $5,000 for that task. i do the same thing everyday."

```
Is this task one I have solved before, priced, for a named customer, deliverable this week? If any answer is no, it is not today's work.
```

## Shape 12: build with a buyer (the only build prompt the gates allow)

Use only after PromptGate passes all four build gates. Modelled on the one engagement that closed cleanly (client-written acceptance test, external deadline).

```
<Named person> committed <time, money, or reputation> on <date>. Their done, in their words: <acceptance test>. Delivery date: <external date>. Build the one hard part first, ship ugly, stop. Log the referral ask as a calendar event on the handover date.
```

## Anti-shapes (the Operator never writes these; each has a date in his history)

- "what's the highest leverage task that can consume a bunch of tokens in the next 5 hours" (2026-07-17, sent twice)
- "wake every five minutes... triage repositories" (2026-07-11; twelve days later: "why the fuck did we spend $14k in credits?")
- "lets build this in full. all ISA." (2026-07-21, the loop that ran fourteen hours)
- "complete this in full. you may use multiple parallel agents" sent to a hobby repo 26 minutes after declaring another repo the only focus (2026-08-05)
- "read everything about the PAI harness... get it all unified in a single repo" typed two minutes before "our biggest weakness is sending messages" (2026-07-02)
- "should we pay for some email placement service to get this done easily" (2026-08-07) before a stranger has paid
- "/model" as the first prompt of a session (82 of 101 times)
- any new idea pasted while a send is pending (four startup ideas forty minutes before "LETS GO WITH A", 2026-05-11)
