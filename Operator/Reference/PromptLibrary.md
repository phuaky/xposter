# Prompt Library

The prompts the founder writes on his best day, extracted from four months of his own prompt history and rewritten as reusable shapes. The Operator reuses these shapes instead of inventing new ones. Each shape names what it produced when the founder used it. Placeholders are in angle brackets.

## Shape 1: the fire page ask (broke a multi-week send drought)

Origin: a job-application submit page the founder asked to reproduce: "you created an artifact. I really liked that. figure out why that was really easy for me to continue to push ahead and agree and send."

```
Turn <send> into a fire page. Verification pre-paid and stamped. Draft in my voice, collapsed, copy without opening. Checklist of six or fewer things only I can do, last one is "fired". No questions on the page. Ten minutes. Then stay until it's sent.
```

## Shape 2: the honest ask draft

Origin: "draft me a message to <name>. read <source> first. then, my ask is unclear: i want to <A>. i want to <B>."

```
Read <thread or dossier> in full first. Draft one message to <name> on <channel>. My ask, in one sentence they can answer yes or no: <ask>. Price exactly as the offer file says. Four sentences max. No AI tells.
```

## Shape 3: criticise before I send (the only review that is allowed)

Origin: "read this in deep detail. and criticise or encourage me sending it. some part of it, I feel, is too <adjective>."

```
Read <artifact> in deep detail once. Tell me the one thing that would make the recipient say no, and fix it in place. Then tell me to send it. Do not offer options.
```

## Shape 4: the voice correction

Origin: "the responses you wrote are not fable level. we dont address <name> with bro. the 2 messages drafted smell of AI and highly lack of context. and seem desperate."

```
This smells of AI, lacks the context in <source>, and sounds desperate. Rewrite with the last two exchanges in front of you. Casual for WhatsApp, not chummy. One ask. Shorter.
```

## Shape 5: what is locking you (unblock without a plan)

Origin: "ok whats currently locking you from finishing up? anything you need me to help you with? if you need help, give me context on what why so?"

```
What is the single thing blocking <deliverable> right now. What, why, so what, in three lines. If it needs me, say exactly what I do and how long it takes. If it doesn't, finish.
```

## Shape 6: scope down to a customer-showable thing

Origin: "i want this to be a shippable working product. i want to scope down to define a clear deliverable. what would be a version we can show to a potential customer and what problem can we solve for them?"

```
Scope <thing> down to the version <named person> can use this week. One problem, one deliverable, their "done" written as an acceptance test they can run themselves. Cut everything else.
```

## Shape 7: build with a buyer (the only build prompt the gates allow)

Use only after PromptGate passes all four build gates.

```
<Named person> committed <time, money, or reputation> on <date>. Their done: <acceptance test in their words>. Delivery date: <date>, external. Build the one hard part first, ship ugly, stop. No polish before delivery. Log the referral ask as a calendar event on the handover date.
```

## Shape 8: the closed-lost ping (one chase, then dead)

Origin: the founder's CHASE-1 rule and the Mr Low and Laurent threads.

```
Draft a two-sentence closed-lost ping to <name>: did this die, a clean no helps me plan. No forward ask. Send today. Mark formal-dead on send. Reopen only if they come back.
```

## Shape 9: the weekly direction question, asked correctly

Origin: the late-night direction prompts ("what do i do?", "is this vanity theatre?") rewritten so they can only be answered from the ledger.

```
From the ledger only: asks fired this week, replies, meetings, cash banked. Which live deal is closest to money and what is its next move. Has a tripwire date passed. One recommendation for next week, two alternatives, no document.
```

## Shape 10: the meta check that saved effort

Origin: "lets get more meta. what does each of the four isa want to solve? and how far have we progressed for each in solving these problems. no point merging everything if we dont know what we are solving."

```
Before doing anything: what problem does <artifact> solve, for whom, and how far along is it. If the answer has no named person in it, stop and say so.
```

## Anti-shapes (the Operator never writes these)

- "build this in full, run in parallel, nothing else" while a send is pending
- "/model" or any prompt about which model, account, or credential to use
- "should we pay for <tool or service> to make this easier" before a send has fired
- "create a new repo and migrate the important stuff" (the fourth migration in four months)
- "rewrite the ISA in full and archive the others"
- any prompt whose output is a plan, spec, dashboard, or tracker instead of a message to a person
